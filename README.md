# Lit-0475-KOTC
0475 KOTC Resources and Revision Guide

Revision resources for Cambridge IGCSE Literature in English 0475 (Paper 1 Prose, examination in 2028). Includes 20 mapped past questions (0486, 2014–2016).

Im_the_King_of_the_Castle_Revision_Guide.pdf – the printable guide (36 pages).
index.html – the same guide as a single web page, with the event bank, quote bank and theme arcs filterable by chapter and theme.
    
References take the form 7 (40%): Chapter 7, about 40 per cent of the way through the chapter, so they work in any edition.
